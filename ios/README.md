# 阅山 for iOS

原生 SwiftUI 交互 Demo。最低系统 iOS 17，面向 iPhone；无真实后端、无第三方依赖。内置原创模拟书库，所有操作在设备本地完成。

## 打开与运行

1. 使用 Xcode 打开 `Yueshan.xcodeproj`。
2. 选择 `Yueshan` scheme 和已安装运行时的 iPhone 模拟器。
3. 按 ⌘R 运行；模拟器不需要开发者账号。安装到真实 iPhone 时需在 Signing & Capabilities 选择你的开发团队。

项目已提交，可直接打开。若修改了文件结构或项目配置，可在仓库根目录运行 `xcodegen generate --spec ios/project.yml` 重新生成工程；日常运行不需要 XcodeGen。

## 完整功能布局预览 v0.3

本轮新增“书源”和“工具”标签，覆盖用户清单中的 47 个模块。完整入口、功能对照、模拟边界和布局调整位置见 [功能覆盖说明](FEATURES.md)。新增部分使用 4 个共享 Swift 文件，目录数据控制表单和预览，便于统一排版。

建议优先体验：工具 → 搜索模块 → 配置 → 预览 → 演示结果，以及发现 → 多源搜索 → 来源切换、工具 → 全文搜索 → 命中跳转、书源 → 编辑 → JSON 校验。

新增解析、网络、朗读、AI、同步和备份能力均用本地模拟状态展示，不连接真实服务；页面统一标注演示。

## 界面和体验路径

- **书架**：继续阅读、阅读状态筛选、网格／列表、最近阅读／加入时间／书名排序、长按进入多选、全选、批量移除与撤销。
- **发现**：iOS 原生搜索框、题材筛选、书籍列表，按书名或作者实时检索。
- **详情**：封面、作者、简介、标签、样章目录、收藏与开始／继续阅读。
- **阅读器**：全屏阅读、上下滚动／左右分页、原生滑动翻页、目录与章节进度滑杆、字号／行距／纸色、两侧轻触都前进、可选轻触翻页和触觉反馈。
- **我的**：本机阅读概况、阅读历史、偏好与 Demo 说明。未收藏或已移出书架的书也能通过历史继续阅读。
- **模拟追更**：书架更新角标与“追更小报”，支持从上次进度继续或直接读更新首章；手动“模拟一次更新”可重置演示标记。
- **首次阅读提示**：第一次进入正文时展示可关闭的手势卡片，关闭后本机不再自动展示；可在阅读设置中点击“查看阅读手势”重新查看。

建议先体验：

1. 书架 → 继续阅读 → 设置 → 左右翻页 → 启用轻触翻页 → 完成；滑动或轻触两侧翻页，中间控制菜单。
2. 拖动底部章节滑杆，松手跳转；调整字号或旋转屏幕，检查当前文字位置是否保留。
3. 书架 → 管理 → 多选 → 移出 → 撤销；也可长按封面进入选择。
4. 书架 → 追更小报 → 从上次继续或读更新首章；读过更新章节后，角标数量减少。
5. 发现 → 搜索“明日” → 不收藏直接阅读 → 我的 → 阅读历史 → 继续阅读或加入书架。

首次运行预置 6 本收藏与 3 条阅读记录。书架、各书章节／段落／文字位置、排序、阅读偏好与演示更新标记保存至 UserDefaults；不会同步至其他设备。卸载或清除 App 数据可重置。示例字数与连载状态仅作展示，正文为短篇样章，多个章节包含复用段落。

手势提示会匹配当前阅读模式：滚动模式说明上下滑动与章切换；左右翻页模式说明左滑下一页、右滑上一页。两侧轻触均前进，但需要先开启“轻触翻页”；卡片会明确显示当前是否开启，不自动修改偏好。中间区域始终用于显示／隐藏工具栏。

首次提示的已读状态独立保存，换书、重新启动 App 或恢复默认阅读设置都不会重复弹出。从设置手动查看不改变首次阅读的展示状态，也不改变当前书籍和阅读进度。已有 Demo 数据升级后，首次进入正文会补充展示一次，原书架和进度保留。

## 演示边界

模拟追更只对内置连载作品的末尾 3 个样章设置更新标记，不会新增真实章节、不访问网络，也不请求系统通知权限。手动模拟会重新设置这些标记，方便重复体验。真实触觉效果需在 iPhone 上体验，模拟器仅能验证开关和调用路径。

横向分页根据屏幕可用区域、字号和行距重新排版；两种阅读模式共用文字位置，改变排版后会定位至包含该位置的一页。原有 v1 收藏与阅读数据会迁移，不需要卸载重装。

阅读正文始终占满屏幕安全区域，上下工具栏以覆盖层显示。轻触中间收起工具栏后，原位置会直接露出正文；再次显示菜单不会重新分页或移动文字。底部只保留少量阅读边距与系统安全区域，不为隐藏的工具栏预留空间。

工具栏沿用首页 Tab 栏的悬浮胶囊样式，两侧留边、底部留空，章节进度独立悬浮在主操作栏上方。顶部书名栏也使用相同圆角材质；浅色与夜读主题自动适配，横屏时限制浮层宽度。

## 测试

在 Xcode 按 ⌘U，或从仓库根目录运行：

```sh
xcodebuild -project ios/Yueshan.xcodeproj -scheme Yueshan \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  CODE_SIGNING_ALLOWED=NO test
```

选择的模拟器名称需与本机实际安装的设备一致。`YueshanTests` 验证模型和持久化，`YueshanUITests` 验证原生 App 操作流程；界面测试使用独立测试数据，不重置正常运行的收藏。

当前验收情况见 `QA.md`。真实书源、云同步、完整小说、付费及离线下载均未实现。
