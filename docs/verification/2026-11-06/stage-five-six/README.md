# 步骤五、六开发记录

## 步骤五首轮验证

2026-11-06，iPhone 17 Pro 模拟器／iOS 26.5，266 项原生单元测试、68 项 Node 测试通过。本轮 3 条 UI 流程通过：真实本地全文命中及阅读计时重启恢复、既有两书三章和离线重启、损坏 EPUB 的系统文件选择及拒绝。日志：本机 `/tmp/yueshan-stage-five-validation.log`、`/tmp/yueshan-stage-five-node.log`。

实现包括：限并发多源检索及候选版本、独立来源路由、章节与上下文映射、换源 SQL 事务及旧历史保留、持久化主动下载队列、Wi-Fi／前台限制、未加密可重排 EPUB 的文字及本地插图、中文全文索引、真实前台计时、书源包预览及版本校验、已支持规则编辑与导出、实际四步调试与批量检测、来源订阅及新增章节提醒。各功能复用原 Demo 的入口和页面组件。

故障验证包括：晚期 SQL 失败回滚、下载中断与重启续传、配额不足与文件提交失败、删除实际下载字节、后台和非 Wi-Fi 不启动、重复及低置信章节映射、正文版本变更重建索引、Unicode 偏移、后台／空闲／改时间不虚增计时、重复更新与回读不重复提醒、书源配置数据库重启恢复。

该记录不代表真实多源内容验收或 G3／G4 通过。此前书山四书共 64 个真实请求仍未取得合格连续正文；新兼容书源需要用户提供可运行配置。iOS 17、真机与签名内测仍缺条件，冻结 RSS 门槛尚未通过。步骤六在线／AI 按用户选择支持自定义兼容服务，密钥只在 App 内配置；音频组合验收后追加记录。
