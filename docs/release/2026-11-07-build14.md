# 竹影 0.8.0（build 14）改动汇总

本包整合主工作区 `master@7c1351d` 与书源兼容分支 `2a3d5b2`。保留双方已有提交，并在独立分支 `codex/ipa-build14` 解决交叉页面的合并冲突；原主工作区源码不覆盖。应用名称为“竹影”，工程、模块及可执行文件名为 `Zhuying`。

## 最初八项问题

1. **书源链接导入**：处理中文 URL、请求及原版阅读 3.0 JSON 包，区分可执行范围与具体兼容错误。大灰狼原包已通过搜索、详情、目录、两部作品各三章和实际重启后的原生请求复核。
2. **章节无法打开**：修复远程书籍／章节引用和初始化结果类型传递；保留阅读记录，原章节确实不可用时仍提供重试及从本章开始的恢复入口。
3. **JSON 粘贴导入**：原书源导入页面的 JSON 文件方式提供粘贴内容入口、预览及确认，不强制用户先生成文件。
4. **系统文件导入**：各本地导入复用原生文件选择器、安全作用域访问和文件协调读取，处理取消、重复点击、文件名与格式错误；书籍、书源和主题等入口继续保留。
5. **主题应用**：应用整套主题真正更新界面与阅读设置并持久化，失败回滚。主题管理、书架和阅读页保持原有导航路径。
6. **朗读时翻页回跳**：区分手动阅读位置与朗读跟随，手动翻页后不再立即被旧朗读位置拉回。
7. **两分钟加入书架提醒**：未收藏书籍在有效前台阅读达到两分钟时询问加入书架；已收藏、离开阅读及已处理提示的状态有对应控制。
8. **朗读小窗**：在正文和离开阅读后提供正在朗读的控制入口，可暂停、继续或返回朗读；与原播放器和阅读进度协作。

## 主题、图标与导入导出

- 全局主题覆盖原页面、顶部导航、底部栏、按钮、图标、背景和阅读配色，浅色／深色保持一致。
- 统一主题管理和封面主题库，支持预览、保存后暂不应用、应用整套、分项混搭、恢复、删除与分享；不增加多余导航层。
- 继续支持阅读字体、SVG 气泡、位图图标和各类阅读样式的自定义。修复位图图标尺寸和含中文路径的主题 ZIP 解包，加入水墨山水浅／深色主题包及验证记录。
- 正式 App 使用竹叶与书本图标；三张替代图标稿保留在设计文档，没有同时嵌入 App。
- 未签名 IPA 导出保持二进制主 Info.plist、正确 Payload 结构、完整 ZIP 本地文件头、权限与 CRC；排除 AppleDouble、Finder 元数据及残留签名材料。

## 阅读 3.0 兼容三阶段

- 规则解析与共享 QuickJS 脚本会话、原生 HTTP、常用 Java／加密接口子集、多主机策略及内部请求引用。
- 原登录表单与网页等待、加密变量／缓存／Cookie、账号代际隔离、稳定资料库 UUID 和可验证的精确旧作用域迁移。
- 保留详情初始化 JSON 对象类型；书籍净化开关真正生效；原生 HTTP 等待与脚本计时分离。
- 进程级脚本堆预留预算、操作租约、空闲回收和取消；逐条搜索脚本有足够额度，同时保留请求、数据、宿主调用和超时限制。
- 安全调试分类、原登录／网络／规则恢复入口、脱敏报告；完整验收要求两书六章正文各异、真实请求及实际进程重启。规则或账号代际改变时，旧通过记录不能沿用。

整合回归额外覆盖“应用夜间主题 → 脚本书源文件导入 → 搜索阅读 → 下一章 → 重启 → 阅读位置与主题均保留”。详细源实测边界见 [阶段三验证记录](../verification/2026-11-07-legado-stage-three.md)。
