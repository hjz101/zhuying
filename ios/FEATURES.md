# 完整功能布局 Demo v0.3

按用户提供的 47 个模块制作 iOS 界面与交互原型。其中本地导入、原生阅读、阅读偏好、字体与主题已接入真实本机数据；其他扩展服务继续用于评估入口、信息层级和步骤。

## 入口安排

- 书架：阅读与管理、分组、智能导入、全文搜索。
- 发现：原有书名／作者检索、多源搜索、分类与订阅。
- 书源：演示书源列表，以及导入、编辑、登录、调试和批量测试。
- 我的：杂志式阅读空间，展示最近阅读、数据摘要和六个快捷入口（历史、偏好、导入、主题、书源、全部工具）。右上角设置收纳界面设置、统计、iCloud、手势帮助与关于。
- 阅读偏好：总览分为主题与字体、排版与页面、翻页与手势、正文与段评；正文设置、个人页与工具箱的对应功能共用同一份本机设置。
- 全部工具：四个可编辑、持久化的常用入口；阅读辅助／导入与文件／书源管理／朗读与声音／主题与外观／数据管理／高级设置七类原地切换，全部视图按组折叠。主要工具与细项分层，搜索仍覆盖完整 47 项，可按当前类别限定范围，演示与部分演示状态明确标注。
- 详情：换源、章节缓存、封面搜索；阅读器：顶部右侧“更多”提供收藏、全文搜索、换源、书签、缓存和净化等。底部独立“朗读”入口提供系统／在线／AI 多角色朗读，“皮肤”入口提供主题管理与段评皮肤。

## 模拟边界

- 智能导入真实读取 TXT 和文字 PDF，自动识别编码及章节，正文保存后进入原生阅读器。PDF 提取文字、不保留原页版式；扫描版、加密 PDF、EPUB、漫画和压缩包提示不支持。其他独立格式功能页仍为排版样例。
- 智能导入仅在用户点击后读取剪贴板或下载 https 文件链接；书源、主题等专用链接使用各自入口。外部链接接入功能页仍为示例，未注册外部 URL Scheme。
- 多书源并发、去重、来源列表、订阅、规则引擎、登录、Cookie、远程请求、DNS／代理、Bing 搜图均为本地模拟；JSON 编辑器做真实语法校验，不执行 JavaScript 或联网。
- 系统／在线／后台／AI 朗读共用播放器、角色和服务配置示意。可切换播放、暂停和进度，跨标签展示迷你播放器；没有声音、后台任务、系统锁屏控制或网络传输。
- 密钥框用于占位演示，仅保留在本次 App 会话内。未接入钥匙串，不应填写真实凭据。
- 备份、iCloud、分享、导出、缓存空间和统计是演示状态，不生成真实备份、不修改真实文件、不清理原有进度，也不进行真实计时或云同步。
- 阅读方向与翻页效果分别选择，横向／纵向分页各自记忆效果；仿真为系统 UIKit 过渡，不是随手指弯曲的纸张模拟。字号、字重、行段距、缩进和四边留白进入实际排版，左右留白可解除联动。正文未提供额外的对齐方式设置。
- 页眉页脚可添加多个内容元素，在各自区域拖动并精调位置、宽度、字号与颜色；区域高度和正文间距参与排版。章节标题只有一个设置入口，可跟随主题或独立自定义，直接编辑不支持的 CSS 会报错并保留有效样式。
- 标题 CSS 的原生白名单包括字号、字重、对齐、颜色、背景色、字距、上下间距和下划线。主题详情分别显示完整网页预览与原生兼容效果；伪元素、侧边框和复杂装饰不会原样应用到正文。SVG 气泡通过本地 WebKit 栅格化后嵌入段末，不加载外部资源。
- 样式规则支持对话、系统提示、诗词、章节首段、关键词与正则，可选择文字高亮、段落底色、居中斜体或首字下沉。诗词使用固定模板匹配，首字下沉为放大并降低基线，不实现多行环绕。规则目前统一作用于全部书籍。
- 段评气泡位于段落末尾，神人评论位于段落下方，可创建或导入圆角／颜色等个人皮肤，也可跟随主题。评论内容和数量仍为本地示例，没有发送或读取真实评论；液态玻璃是半透明绘图外观，不实时模糊背后文字。
- 主题、样式资源、收藏、搭配及字体文件在本机持久化，个人样式在切换主题时保留。工具演示配置、书源、演示文件清单、书签、下载状态和播放器仍仅在本次 App 会话保留；真实导入的正文、分组、书架、进度和阅读偏好在本机持久化。
- 本轮新清单明确包含书签，因此补充了轻量书签演示入口，覆盖先前“书签暂缓”的范围决定；笔记功能不在本轮。

## 如何调整布局

- `Yueshan/Demo/FeatureCatalog.swift`：47 个模块的文案、分组、字段、按钮及相关入口。
- `Yueshan/Demo/FeatureDemoView.swift`：工具目录、共享配置表单及页面结构。
- `Yueshan/Demo/DemoPreviews.swift`：书源卡片、播放器、画布、规则、评论、图表和文件阅读样例。
- `Yueshan/Demo/FeatureDemoStore.swift`：演示状态与动作；不建立通用书源引擎。
- `Yueshan/Views/SmartImportView.swift`：来源切换、系统文件选择、预览清单和确认导入。
- `Yueshan/Models/BookImport.swift`：真实文件解析、导入队列、重复检测与失败重试；正文归档由 `LibraryStore` 管理。
- `Yueshan/Views/ReadingPreferencesView.swift`：偏好总览、文字与边距、翻页与手势及阅读预览。
- `Yueshan/Views/ReadingPageEditors.swift`：章节标题 CSS 编辑与自由页眉页脚。
- `Yueshan/Views/ReadingAppearanceView.swift`、`ReadingContentPreferences.swift`：主题／字体入口、样式规则与段评皮肤。
- `Yueshan/Models/ReaderPreferences.swift`、`ReaderEngine.swift`：偏好迁移与校正、标题／规则解析、真实正文排版与分页。
- `Yueshan/Models/ReadingFontLibrary.swift`、`ThemeReadingBridge.swift`：本地字体注册、主题持久化与原生阅读桥接。

通用演示模块共用 Demo 配置和预览文件，智能导入与阅读偏好使用独立页面和模型，没有引入第三方依赖或账号后端。
