## 重现

```sh
python3 ios/scripts/convert-ink-mountain-theme.py \
  /path/to/水墨山水-孤舟-主题包.zip \
  --output /path/to/new-output-directory
```

转换工具只读取配置和素材，不运行压缩包中的任何内容；拒绝不安全路径、重复路径、超限或加密条目。输出是具有确定字节、完整资源清单、真实 SHA-256 和完整本地文件头的标准 ZIP；拒绝覆盖已有成品。

验证覆盖 ZIP 完整性、文件闭包／哈希、字体／许可、原生 CSS 与 SVG、完整应用、保持阅读行为及浅深两版的真实文件导入与阅读。原生测试使用这里的实际成品，不依赖用户设备上的原始 ZIP。
