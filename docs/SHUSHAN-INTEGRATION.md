# 书山聚合接入记录

日期：2026-11-05。来源为用户提供的 v5.61 书源文件静态规则，未执行该文件的 JavaScript。以下为固定原生适配，不代表通用 legado 兼容。

## 已实现的契约

| 能力 | 请求 | 处理边界 |
| --- | --- | --- |
| 登录 | HTTPS 主机的 POST /login，表单邮箱和密码 | 检查 HTTP 与业务 code、user.api_key；密码不持久化，登录结果入设备钥匙串 |
| 搜索 | GET /search，login=search、key、page | 空输入不请求、来源版本去重；分页默认关闭，需真实确认后开启；显示真实认证错误 |
| 详情 | POST /details，source、url、cover、desc、name | 原作品身份保留，更新来源参数与真实可选字段，只启用文字小说路径 |
| 目录 | POST /catalog，source、url、name、bookid、tab | 稳定 cid／来源章节 URL，分卷不可读，受限标记不当作普通正文；重复章节身份报错 |
| 正文 | POST /content，目录生成的来源参数 | 规范化段落，支持明文与 UTF-8 Base64；不执行 HTML／JS，不把未知编码当成功正文 |

认证头按参考宿主契约转换返回的用户 API Key；不把真实凭据写入 URL、普通偏好、报告或提交。HTTP 会话阻止跨来源重定向，避免带凭据的请求被转给其他主机。

默认主机 `https://v1.vossc.com` 的未认证搜索探测返回 HTTP 200，但业务响应明确为缺少登录凭证。用户已选择在原生应用内登录；真实登录、分页、两本书各三章、受限章节与服务失败仍需联调，T003／G1 未完成。

原生入口复用 Demo 的“我的 → 书源管理 → 书源详情 → 登录”，保留分类、搜索、管理、详情和左滑／长按路径；在书山聚合登录页输入实际账号。界面和交互遵守 AGENTS.md，示例来源及响应时间不进入正式源列表。
