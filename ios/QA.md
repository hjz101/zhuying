# iOS 原生 Demo 验收记录

日期：2026-11-04。平台已明确为 iOS；本目录为 SwiftUI 原生工程，仓库根目录的网页仅保留为历史草稿。

## 构建环境

- Xcode 26.6，iOS 26.5 Simulator。
- iPhone 17 Pro 模拟器；工程最低支持 iOS 17，当前尚未逐一验证其他 iOS 版本和真实设备。
- Debug 模拟器构建关闭代码签名，无外部依赖、真实后端或网络请求。

## 自动化验证

`YueshanTests` 共 8 项，通过：

1. 模拟书库、章节正文完整性与默认书架。
2. 书名、作者、题材交集搜索及无结果情况。
3. 移除收藏后保留进度、重新加入不重复。
4. 未收藏书籍的阅读记录与章节边界。
5. 重新创建数据模型后恢复收藏、段落、字号、行距和主题。
6. 清空书架后保持空状态，历史进度仍保留。
7. 损坏数据回退并给出提示。
8. 已保存数据去重、排除无效书籍和范围校正。

`YueshanUITests` 共 2 项，通过：

- 书架继续阅读第三章 → 目录跳第五章 → 关闭目录 → 阅读设置 → 夜读与 24 pt 字号 → 退出阅读器 → 再次继续第五章。
- 发现 → 原生搜索框输入“云海” → 详情 → 收藏 → 阅读第一章 → 返回书架看到该书。

原网页的 JavaScript 语法检查与 12 项逻辑测试也已通过。

## 界面检查与交付

- 在 Simulator 中打开正常运行的 App，确认原生状态栏、安全区域、导航栏、底部标签栏与全屏阅读。
- 使用系统搜索、原生导航返回、目录及偏好 sheet；没有在 WebView 中包装原网页。
- 初始书架预置 6 本收藏和 3 条阅读记录；界面测试使用独立的 UserDefaults 域。
