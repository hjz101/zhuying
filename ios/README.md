# 阅山 for iOS

原生 SwiftUI 应用，正式版正在按任务清单开发。最低系统 iOS 17，面向 iPhone；Demo 保留原创模拟书库，正式模式使用独立数据。正式书架、导入正文、进度与排版偏好已接入 GRDB／SQLite 和章节文件仓库；智能导入支持实际文件读取和用户主动发起的文件链接下载。

## 打开与运行

1. 使用 Xcode 打开 `Yueshan.xcodeproj`。
2. 选择 `Yueshan` scheme 和已安装运行时的 iPhone 模拟器。
3. 按 ⌘R 运行；模拟器不需要开发者账号。安装到真实 iPhone 时需在 Signing & Capabilities 选择你的开发团队。

项目已提交，可直接打开。若修改了文件结构或项目配置，可在仓库根目录运行 `xcodegen generate --spec ios/project.yml` 重新生成工程；日常运行不需要 XcodeGen。

## 完整功能布局预览 v0.3

默认导航为书架、足迹、我的及独立搜索，书源与工具可按需加入导航，覆盖用户清单中的 47 个模块。完整入口、功能对照、模拟边界和布局调整位置见 [功能覆盖说明](FEATURES.md)。通用演示使用共享配置和预览；智能导入、阅读偏好、字体与主题使用独立的原生页面和模型。

建议优先体验：我的 → 全部工具 → 搜索模块 → 配置 → 预览 → 演示结果，以及发现 → 多源搜索 → 来源切换、我的 → 全文搜索 → 命中跳转、书源 → 编辑 → JSON 校验。

智能导入可真实读取 TXT 和文字 PDF，保存正文后进入原生阅读器。书源网络、朗读、AI、同步和备份等其他扩展能力仍用本地模拟状态展示，相关页面标注演示。

## 界面和体验路径

默认底部导航为“书架、足迹、我的”，右侧提供独立搜索。可在“我的 → 界面设置 → 底部导航”选择足迹／发现／书源／工具、调整顺序，并开启“滑动时自动收起导航”；开关默认关闭，主导航最多四项。iOS 26 支持原生独立搜索与自动收起，较早系统使用固定导航。完整规则见 [导航与足迹说明](NAVIGATION.md)。

“足迹”支持日／周／月／年统计：小时与每周柱状图、月历热力图、全年热力图／月度柱状图；总时长、同期比较与书籍排行随周期联动。点击日期查看当天各书时长，排行支持展开全部，点击书籍查看阅读会话并继续阅读。书源管理和全部工具也可从“我的”进入。

从“我的 → 全部工具”进入紧凑工具目录：顶部常用工具最多四个，默认智能导入／全文搜索／主题管理／书源管理，支持长按替换、前后移动和移除；列表中的工具可长按加入常用，满额时进入编辑。编辑页提供删除、拖动排序和添加，选择与顺序保存在本机，允许留空。

下方在阅读辅助／导入与文件／书源管理／朗读与声音／主题与外观／数据管理／高级设置七类之间原地切换，不再进入二级分类页。“全部”视图按组折叠，单类直接展示主要工具，格式演示和细项在组内展开。顶部搜索覆盖全部 47 项目录，选择分类时限定范围，清空后恢复分类和展开状态。书源管理直达实际列表，数据分类的阅读统计进入与足迹相同的多周期统计页；其统计数据仍为示例。

演示功能标注“演示”，含真实操作与模拟部分的工具标注“部分演示”；智能导入和本地全文搜索不显示演示角标。各格式独立演示页保留在“格式支持与演示”和搜索中，真实文件统一从智能导入选择。

- **书架**：标题右侧使用小说／漫画／听书紧凑分段，默认小说；窄屏或辅助大字号时移到标题下方，全部／在读／未读与排序、布局、管理合并为轻量工具栏；继续阅读、阅读状态筛选、两列／三列／四列／列表／书脊与封面布局、最近阅读／加入时间／书名排序、长按进入多选、全选、批量移除与撤销。
- **发现**：iOS 原生搜索框、题材筛选、书籍列表，按书名或作者实时检索。
- **详情**：封面、作者、简介、标签、样章目录、收藏与开始／继续阅读。
- **阅读器**：全屏阅读、上下滚动／左右翻页／上下翻页、方向与效果分别设置、目录与章节进度滑杆；正文排版、主题、本地字体、章节标题、页眉页脚及样式规则与阅读偏好联动。两侧轻触都前进，可选轻触翻页和触觉反馈。
- **我的**：杂志式阅读空间，包含大标题、最近阅读书籍、轻量数据和细线分区。最近阅读来自本机历史（含已移出书架的书），“接着读”恢复实际进度；没有历史时提供去书架入口。今日分钟与足迹一样为示例数据，收藏与已读数量来自本机记录。下方入口为阅读历史、阅读偏好、智能导入、主题管理、书源管理、全部工具。界面与导航设置从右上角设置进入，缓存和备份等仍在全部工具中。
- **模拟追更**：书架更新角标与“追更小报”，支持从上次进度继续或直接读更新首章；手动“模拟一次更新”可重置演示标记。
- **首次阅读提示**：第一次进入正文时展示可关闭的手势卡片，关闭后本机不再自动展示；可在阅读设置中点击“查看阅读手势”重新查看。

建议先体验：

1. 书架 → 继续阅读 → 设置 → 翻页与手势 → 左右翻页 → 选择效果并启用轻触翻页 → 完成；滑动或轻触两侧翻页，中间控制菜单。
2. 拖动底部章节滑杆，松手跳转；调整字号或旋转屏幕，检查当前文字位置是否保留。
3. 书架 → 管理 → 多选 → 移出 → 撤销；也可长按封面进入选择。
4. 书架 → 追更小报 → 从上次继续或读更新首章；读过更新章节后，角标数量减少。
5. 右侧搜索 → 输入“明日” → 不收藏直接阅读 → 我的 → 阅读历史 → 继续阅读或加入书架。

首次运行预置 6 本收藏与 3 条阅读记录。书架、各书章节／段落／文字位置、排序、阅读偏好与演示更新标记保存至 UserDefaults；不会同步至其他设备。卸载或清除 App 数据可重置。示例字数与连载状态仅作展示，正文为短篇样章，多个章节包含复用段落。

手势提示会匹配当前阅读模式：滚动模式说明上下滑动与章切换；左右翻页模式说明左滑下一页、右滑上一页；上下翻页模式说明上滑下一页、下滑上一页。两侧轻触均前进，但需要先开启“轻触翻页”；卡片会明确显示当前是否开启，不自动修改偏好。中间区域始终用于显示／隐藏工具栏。

首次提示的已读状态独立保存，换书、重新启动 App 或恢复默认阅读设置都不会重复弹出。从设置手动查看不改变首次阅读的展示状态，也不改变当前书籍和阅读进度。已有 Demo 数据升级后，首次进入正文会补充展示一次，原书架和进度保留。

## 阅读偏好

从正文底部“设置”或“我的 → 阅读偏好”进入同一个偏好总览。四个分组为“主题与字体、排版与页面、翻页与手势、正文与段评”，总览显示当前搭配与阅读预览；修改自动保存在当前设备，正文和工具箱对应入口共用同一份设置。

- **主题与字体**：选择内置纸色或进入主题库，“我的导入”筛选显示自导入套装。字体管理通过系统文件选择器实际读取 TTF／OTF／TTC，单文件最多 20 MB；卡片以该字体显示样张，并可输入自己的预览文字。选中的本地字体用于正文，文件和字体清单在本机保存。
- **排版与页面**：正文排版集中设置字号、字重、行间距、段落间距、首行缩进和四边留白。关闭“左右边距联动”即可独立设置左大右小。章节标题只有一个设置入口，可跟随主题或保留个人样式；可视控件、自建 CSS、导入 CSS 共用实时预览。页眉和页脚可分别开启，添加书名、章节、时间、进度或自定义文字，在区域内拖动并精调位置、宽度、字号和颜色；区域高度与正文距离参与真实阅读页排版。
- **翻页与手势**：上下滚动、左右翻页、上下翻页分开选择。横向支持平移、覆盖、仿真、无动画；纵向分页支持平移、覆盖、无动画，两方向独立记忆效果。仿真使用系统 UIKit 翻页过渡，不是随手指弯曲的书页模拟。设置内可试读效果并查看手势说明。
- **正文与段评**：规则可自建、编辑、排序、启停及导入 JSON，支持对话、系统提示、诗词、章节首段模板，以及关键词或正则匹配；呈现可选文字高亮、段落底色、居中斜体、首字下沉。目前规则统一作用于全部书籍，诗词识别为模板匹配，首字下沉为放大并降低基线。段评气泡位于段末，神人评论卡片位于对应段落下方；气泡和卡片可跟随主题或自建／导入个人皮肤。评论内容与数量仍为本地示例，液态玻璃为绘制的半透明外观。

原生标题支持 `.chapter-title` 的字号、字重、对齐、颜色、背景色、字距、上下间距和下划线子集。直接编辑或导入不支持的 CSS 会提示错误并保留上次有效样式；主题包的完整网页 CSS 与原生兼容效果分别预览。个人标题、气泡与神评皮肤可覆盖主题，切换套装时保留个人选择。恢复默认偏好不删除已导入字体，也不改变阅读进度。

## 主题套装与样式资源

主题管理提供“主题套装／章节标题／段评气泡”三栏。顶部当前搭配为紧凑摘要；套装卡片实际渲染配色、CSS 章节标题和 SVG 段评气泡，并显示附带数量。独立标题、气泡显示所属套装或独立来源，支持收藏、搜索及批量管理。

套装详情提供整页组合预览、正文实际效果、附带资源选择与长标题开关；气泡详情对比 3／28／128 条段评，可切换深浅背景。“应用整套”应用阅读配色与主题组件，“仅应用配色”保留组件；“自定义搭配”允许选择不同套装的配色、标题和气泡。缺少的组件保留当前样式；当前使用中的组件不能删除，删除其他组件同步更新套装引用，删除套装保留可独立使用的资源。

导入菜单支持选择实际 JSON 文件和导入示例套装，分别统计新增主题、标题、气泡及重复／无效项。无效资源不会当作正常缩略图展示，详情与导入结果会提示。支持自包含 CSS／SVG，不加载外部图片、字体或脚本；格式与限制见 [套装文件说明](THEME_PACKAGES.md)。主题、资源、收藏及当前搭配在本机保存；应用后配色、兼容标题与栅格化 SVG 气泡接入原生阅读器，个人自定义样式保留。

## 智能导入

从“我的 → 智能导入”、工具箱或书架进入。本地文件为默认来源，通过“选择文件”打开系统“文件”，支持多选和 iCloud 文件；书架右上角“＋ → 本地导入”直接打开同一个选择器。取消选择不改变书架。

导入前展示实际文件名、大小、编码、章节数、正文预览和识别状态，可逐项取消选择或移除，并选择加入分组。底部确认按钮只处理可导入且选中的项目，完成后显示成功／重复／失败数量、查看书架和失败重试。编码选项用于下一次识别或重试。

实际支持 TXT（UTF-8／UTF-16／GB18030，自动识别中英文章节）与有文字层且未加密的 PDF（提取正文使用文本阅读器）。单文件最多 20 MB，PDF 最多 2000 页；扫描版 PDF、EPUB、漫画和压缩包明确提示暂不支持，不会替换成示例书。PDF 导入不保留原页版式。

链接来源仅在点击识别后下载 https 文件直链；剪贴板仅在点击读取后访问，可识别文件链接或保存纯文本。书源／主题专用链接转为说明提示，使用对应管理页处理。文件内容按正文哈希去重；原文件不会被删除或修改。导入正文单独保存在 App 支持目录，书架、分组与阅读进度随本机记录保存，重启后可继续阅读，无需再次访问原文件。

## 书源快捷操作

从“我的 → 书源管理”或自定义的书源 Tab 进入紧凑两行列表。顶部按全部／小说／漫画／听书分类并显示数量，搜索名称、网址或分组；筛选菜单提供启用／停用、登录过期、异常和自定义分组，支持响应速度与名称排序。长按置顶后书源始终排在当前结果前方，取消置顶恢复排序。分类与分组独立，移动分组不会改变小说／漫画／听书类别。

右上角“＋”收纳统一的“导入书源”和手动新建，“更多”收纳导出、批量检测和规则调试。导入页用“链接／文件”分段切换：链接支持 URL 与阅读分享链接的示例预览，不下载网络内容；文件提供系统“选择 JSON 文件”入口，支持最大 5 MB 的单个书源或书源数组，读取名称、网址、分组、启用状态和漫画类型。预览列出可新增、重复和无效数量，确认后才加入当前列表，按网址跳过重复。导入只保留本次运行的基本信息，不保存或执行解析规则；导出在独立折叠区预览当前列表的基本信息 JSON，不写入文件。检测仍为模拟流程；手动新建添加本次预览中的独立书源并打开对应编辑页。点击“管理”进入多选，可全选当前结果、启停、移动至已有或新建分组、确认删除。切换分类、分组、状态或搜索会清空选择，避免处理隐藏结果；删除保留书架和阅读进度。

左滑单个书源显示登录／编辑，完整左滑不会自动执行。长按可登录、编辑、调试、启停、移入个人收藏或删除，删除需在弹窗中确认。点击书源进入详情，详情保留明显的登录入口。登录、编辑和相关功能自动带入对应书源，避免重新选择。

列表显示未登录／已登录／登录已过期三种演示状态，入口分别显示登录／管理登录／重新登录。模拟登录和清除演示 Cookie 会更新当前书源状态，其他书源保持独立。书源、置顶、分组及状态仅保存在本次预览内，不检测真实 Cookie 或发送登录请求；响应时间和异常状态为示例数据。功能预览中的内嵌书源卡片支持点击详情与长按操作；原生左滑快捷操作在书源主列表使用。

## 演示边界

书架默认三列，通过筛选栏右侧的“书架布局”菜单选择两列大封面、三列标准、四列紧凑、列表或“书脊与封面”，选择会保存在当前设备。两列保留作者、章节和进度条；三列保留书名与简短进度；四列隐藏次要信息并用圆点提示更新。三列／四列可长按封面打开更多操作，两列还提供封面菜单。旧版网格／列表切换未持久化，升级后统一默认三列，已有收藏与进度保留。

“书脊与封面”采用浅色层板与竖排书脊混排，当前可见作品中最近读过的一本正面展示封面，其余书籍显示书脊；没有阅读记录时展示当前结果中的第一本封面。该模式由正面封面提供继续阅读入口，收起上方大卡片，让混排书架更早呈现。混排遵循当前排序和阅读状态筛选，不重复或混入隐藏书籍，宽度与每排本数随可用空间调整。书脊沿用封面配色，显示作者、底部进度细条与更新书签，超长书名使用双列或省略；点击恢复阅读，长按提供选择多本、继续阅读和移出操作，切换布局保留多选状态。

内置作品均为小说，漫画和听书栏目目前展示各自的空书架。收藏数量与阅读状态筛选按当前栏目显示，切换栏目会重置到“全部”并清空批量选择；漫画与听书不展示小说的继续阅读和追更小报，小说收藏、进度和排序保持不变。

模拟追更只对内置连载作品的末尾 3 个样章设置更新标记，不会新增真实章节、不访问网络，也不请求系统通知权限。手动模拟会重新设置这些标记，方便重复体验。真实触觉效果需在 iPhone 上体验，模拟器仅能验证开关和调用路径。

横向与纵向分页根据可用区域、字体、字号、行段距、边距和页眉页脚重新排版；三种阅读模式共用文字位置，改变排版后会定位至包含该位置的一页。原有收藏、阅读位置与基础偏好会迁移，新增设置使用默认值，不需要卸载重装。

阅读正文始终占满屏幕安全区域，上下工具栏以覆盖层显示。轻触中间收起工具栏后，原位置会直接露出正文，底部不保留“显示工具栏”按钮；再次轻触正文中间唤回菜单，不会重新分页或移动文字。底部只保留少量阅读边距与系统安全区域，不为隐藏的工具栏预留空间。

工具栏沿用首页 Tab 栏的悬浮胶囊样式，两侧留边、底部留空，章节进度独立悬浮在主操作栏上方。顶部书名栏也使用相同圆角材质；浅色与夜读主题自动适配，横屏时限制浮层宽度。

顶部右侧“更多”集中提供收藏／取消收藏、全文搜索、换源、书签、缓存与正文规则。底部固定为“目录、设置、朗读、皮肤”：朗读可选系统、在线和 AI 多角色；皮肤可进入主题管理与段评皮肤。打开后以弹层展示，完成后回到当前阅读位置。

## 测试

在 Xcode 按 ⌘U，或从仓库根目录运行：

```sh
xcodebuild -project ios/Yueshan.xcodeproj -scheme Yueshan \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- test
```

选择的模拟器名称需与本机实际安装的设备一致。`YueshanTests` 验证模型和持久化，`YueshanUITests` 验证原生 App 操作流程；界面测试使用独立测试数据，不重置正常运行的收藏。

新增钥匙串集成测试需要模拟器的临时签名，`CODE_SIGN_IDENTITY=-` 无需开发者证书；不要关闭签名后将钥匙串失败当作通过。统一验证命令为 `bash ios/scripts/verify.sh unit`，`ui` 运行界面流程，`all` 运行全部；脚本目标为模拟器，真机签名在 Xcode 中配置。

性能基线使用独立的 `Yueshan Performance` scheme，命令为 `bash ios/scripts/verify.sh performance`；日常 `all` 指功能测试，性能负载单独运行。固定负载、冻结目标、原始样本与未达标项见 [性能基线](../docs/PERFORMANCE-BASELINE.md)。基线测试验证测量与内容正确性，性能门槛是否达标须核对报告中的 `withinTarget`。

使用 `Yueshan Production` scheme 运行正式模式，或使用 `--production` 启动参数；`Yueshan` 的 Debug 启动保留 Demo。两者共用原有界面，数据独立。正式模式“我的 → 书源管理 → 书山聚合 → 登录”提供原生登录入口；在线阅读尚需完成后续接入与登录联调，不能据登录页面可用宣称正式版已完成。

正式本地流程：我的 → 智能导入 → 选择 TXT／文字 PDF → 预览确认 → 查看书架 → 阅读。旧正式归档、收藏、分组、进度及阅读偏好首次启动自动迁移并保留原件，后续从数据库恢复；迁移失败可重试。切章、退出阅读和后台补存，持续阅读节流保存；保存失败会提示并保留上次有效记录。正文暂以整本投影复用 Demo 阅读器，按章懒加载及完整 G2 验收继续开发。

当前验收情况见 `QA.md`。真实书源、云同步、完整小说、付费及离线下载均未实现。
