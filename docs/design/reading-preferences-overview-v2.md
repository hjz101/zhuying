# 偏好总览 · 第二版设计评审

2026-11-05。本稿仅用于设计评审，不修改 App，也不表示所述能力已经实现。交互原型源文件为同目录 `reading-preferences-overview-v2.html`。

保留“偏好总览”的简洁首页，将当前样式摘要、正文效果与四个明确分类放在一起：**主题与字体／排版与页面／翻页与手势／正文与段评**。不再设置一个囊括所有功能的“更多阅读设置”清单。

## 主题与字体

### 主题库与导入主题

主题库分为“内置／我的导入／我的创建”。每张主题卡使用同一段示例内容，直接预览纸色、正文、章节标题、段尾气泡及神人评论卡片。主题名称、作者与来源作为辅助信息；自导入主题与内置主题获得相同的预览能力。

主题详情列出包内实际包含的组件，如配色、字体引用、章节样式、段尾气泡皮肤和神评卡片主题，避免将完整主题误解为单一纸色。未包含的组件继续沿用现有设置。导入先预览，再应用。

### 字体管理

字体列表中的试字直接使用对应字体，不能仅显示字体名称或字体截图。选择后，上方正文预览同步切换；可输入自定义试字，并提供中文、标点、数字和字母混排示例。导入、收藏与查找集中在字体管理页，缺字使用回退字体时明确提示。

## 排版与页面

### 正文排版与独立边距

字号、字重、行距、段距、缩进、对齐和四边留白在同一分类内调整。左右边距默认联动；解除联动后分别设置左边距和右边距，允许左边较大、右边较小。预览同步显示实际可用正文宽度，并限制边距总量，保留可读空间。

### 章节标题的唯一入口

章节标题仅在“排版与页面 → 章节标题”中管理，提供样式库、新建 CSS、导入 CSS、编辑和实时预览。主题页只展示“主题包包含章节样式”“当前跟随主题”或“当前已自定义”等状态；若需要查看或编辑，跳到同一个章节标题页，不维护第二套设置。

章节 CSS 只作用于章节标题区域，可调整字体、字号、颜色、对齐、间距、背景和装饰。导入或编辑后，示例章节标题实时变化，并反馈不兼容或无效规则。原生 SwiftUI 阅读器不能直接运行任意网页 CSS；实际实施需要限定支持范围并建立 CSS 到原生样式的兼容层。该兼容层目前尚未实现，原型中的浏览器预览不代表 App 已支持完整 CSS。

### 页眉与页脚

页眉、页脚分别启停，在左／中／右三个位置放置书名、章节、时间、进度等信息；可设置文字颜色、字号及与正文的距离。分页模式可展示页码，滚动模式使用章节进度。预览同时展示页眉、正文与页脚，避免额外信息挤占阅读区域。

## 翻页与手势

滚动／分页是阅读模式；覆盖、平移、无动画、仿真是分页效果，只在选择分页时展开。轻触翻页、触觉反馈及手势说明放在同一分类。两个模式继续共享阅读位置。

## 正文与段评

### 从关键词高亮升级为正文样式规则

规则库支持新建、导入、排序、启停及样式预览。每条规则由“匹配对象或条件 → 呈现样式 → 作用范围”组成，关键词高亮只是一种匹配与呈现组合。

对话、系统消息、诗词和章节首段首字下沉作为可修改模板；可使用关键词、正则或已识别的文本结构作为条件。规则编辑页显示示例内容中的命中范围与未命中反馈，不将诗词或对话识别描述为无条件准确。首字下沉属于排版变换，不再等同于给固定字染色。重叠规则的优先级与冲突结果需要清楚可见。

### 段尾气泡与神人评论

- **段尾气泡**：紧接段落末尾，显示评论数量并打开该段评论。皮肤可调整气泡形状、计数文字、颜色与装饰，始终保留可点击区域。
- **神人评论**：作为对应段落下方的精选评论卡片呈现，可控制数量或折叠。卡片主题可采用液态玻璃、画框、纯文字等形式，独立调整背景、边框、圆角、头像与文字样式。

管理页分为“段尾气泡／神人评论”，分别设置显示行为和外观。两类组件都支持随完整阅读主题导入，也支持独立创建或导入皮肤；不得把段尾气泡与段下评论卡片混成同一种组件。

## 主题继承与个人覆盖

外观采用“应用默认 → 当前主题包 → 用户单项自定义”的优先级。字体、章节标题、正文样式规则、段尾气泡和神评卡片等组件显示“跟随主题／自定义”状态；允许一键恢复跟随。

应用新主题时，默认保留用户明确设置的单项覆盖，并在主题详情中列出这些覆盖；提供主动选择使用包内样式的操作。主题包没有携带某个组件时，不清空用户当前设置。全局偏好与规则的作用范围分别表达，不将当前书独有规则误当成全局主题。

## 原型与实现边界

原型演示信息组织、主题／字体预览入口、章节 CSS 编辑、独立边距、页眉页脚、正文样式模板及两种评论组件之间的关系。预览中的导入与创建能力以原型实际行为为准，不能据此宣称已经完成文件持久化、原生渲染、真实评论服务或跨设备同步。

目前真正作用于原生阅读器并持久化的基础设置仍以 App 现有实现为准。实施本方案时，应统一主题库、字体、排版、章节样式和评论皮肤的数据来源与继承关系，并新增相应模型、迁移、渲染与测试。本次设计评审不修改这些 App 能力。
