## 候选构建与追踪

先确保源码已提交且工作区干净。构建时传入 `YUESHAN_SOURCE_REVISION=<完整 Git commit>`，该值写入 App 的 Info.plist；打包脚本会拒绝平台混淆、未提交源码或构建记录与当前提交不一致的 App。使用独立 DerivedData，设备归档指定 `generic/platform=iOS`、Release 和 `CODE_SIGNING_ALLOWED=NO`；模拟器构建指定模拟器目的地、Release 和临时签名。

构建后执行 `python3 ios/scripts/package-candidate.py --app <绝对 App 路径> --output <输出目录> --kind simulator`，设备 App 改用 `unsigned-device`。本地交付放在 Git 忽略的 `artifacts/0.4.0/`。脚本输出 ZIP 及对应 JSON，包含版本、构建、完整提交、平台、SHA-256、大小和 `releaseGate=not-approved`。模拟器包只用于模拟器；未签名设备归档不能直接安装到 iPhone，也不是签名内测包。文件保存在本机，不自动上传。

## 回滚与恢复

升级前先在“本地备份”导出原生备份。恢复在独立目录构建新库；激活点是 `active-generation.json` 的原子替换，旧数据库／资源目录保留。文件或数据库失败发生在激活前时，旧库继续有效。损坏备份、未知版本和资源缺失不激活。若已成功切换后需要回退，应由维护工具在离线关闭 App 后将激活指针还原到确认有效的先前代；不要在运行中直接复制 SQLite 文件或删除原代。Git 变更按提交回退，数据格式需按兼容性核对。
