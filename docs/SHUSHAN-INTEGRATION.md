## 已实现的契约

| 能力 | 请求 | 处理边界 |
| --- | --- | --- |
| 登录 | HTTPS 主机的 POST /login，表单邮箱和密码 | 检查 HTTP 与业务 code、user.api_key；密码不持久化，登录结果入设备钥匙串；安装级 UUID 随登录与正文请求保持一致 |
| 搜索 | GET /search，login=search、key、page | 空输入不请求、仅保留小说、来源版本去重；聚合站部分失败保留有效结果并标记；认证错误不降级为空成功；分页默认关闭 |
| 详情 | POST /details，source、url、cover、desc、name | 原作品身份保留，更新来源参数与真实可选字段，只启用文字小说路径 |
| 目录 | POST /catalog，source、url、name、bookid、tab | 读取真实 title 字段；cid 可为请求下标，优先章节 URL 作为身份，无 URL 时用唯一标题回退，重名报错；分卷与受限章不可读 |
| 正文 | POST /content，目录生成的来源参数、version=12 | 文件版本 v5.61 与接口版本 12 分开；发送 X-Device-Type／X-Device-Id，规范化段落；支持明文与 UTF-8 Base64，拒绝其他媒体及未知编码 |

认证头按参考宿主契约转换返回的用户 API Key；不把真实凭据写入 URL、普通偏好、报告或提交。HTTP 会话阻止跨来源重定向，避免带凭据的请求被转给其他主机。

安装标识是当前模式／安装单独生成的 UUID，不读取设备 UDID 或其他应用标识。旧钥匙串记录缺少此字段时，在请求内补用已持久化的安装 UUID，不要求用户交出密码。HTTP 201／业务 status=201 的设备、认证或会员提示不会写成小说正文；HTTP 503 等作为服务失败处理。

默认主机 `https://v1.vossc.com` 的未认证搜索探测返回 HTTP 200，但业务响应明确为缺少登录凭证。用户已选择在原生应用内登录；真实登录、分页、两本书各三章、受限章节与服务失败仍需联调，T003／G1 未完成。
