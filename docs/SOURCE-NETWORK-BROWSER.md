# 书源网络与浏览器 v1

沿用 Demo 的工具入口、页面标题、设置卡片与导入预览路径。

- 每书源＋HTTPS 主机独立持久 WebKit 会话；临时浏览不落盘。原生 Cookie 默认不复用，需应用内明确打开；域、路径、有效期、同源均校验。书山使用原生应用内登录，不取浏览器 Cookie。
- 浏览器支持前后退、刷新／停止、网页脚本开关、去除输入与脚本后的 DOM 调试、公开 WKDownload 下载。文件最多20 MiB、45秒；下载后仍经过原导入预览确认。取消和失败清除临时文件。
- 网络配置按书源＋主机保存在本机：系统、无认证 HTTP CONNECT、指定 IPv4／IPv6、UDP DNS A／AAAA／CNAME。DNS 缓存上限100项／600秒，响应事务、问题、类型、压缩指针、截断及错误码校验；不支持 DoH、DoT、TCP回退或代理账号。
- 指定 IP／DNS 通过只监听127.0.0.1的专用 CONNECT 隧道，4条连接、背压、64MiB流量和超时边界。URLSession／WebKit 保留原始 HTTPS URL、SNI 和系统证书验证；代理不可用不直连，不修改系统 DNS。
- 应用于原生书源读取、书山登录、真实段评、允许联网的脚本桥和当前源浏览器；脚本仍不获账号或 Cookie。浏览器外站需临时会话确认；跨站子资源走系统网络。局域网配置不随书库备份传递。

自动化覆盖源／主机隔离、真实 WebKit Cookie 保存与清理、原生 UDP DNS 与取消、错误响应、未知长度上限、浏览器 URL／文件类型和外站确认。2026-11-06模拟器实际 App 探测：example.com 指定IP HTTPS 返回200且隧道计数1；self-signed.badssl.com 返回系统TLS错误−1200且隧道计数1；Gutenberg TXT下载772386字节，预览62章。结果见同目录验证报告；不是实际设备网络、所有站点或所有代理协议的验收。
