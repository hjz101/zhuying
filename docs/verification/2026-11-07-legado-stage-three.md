实际调用使用 Production 环境、普通书源适配器和受控原生 HTTP。第一次四步诊断已取得搜索结果、详情、144 条目录项及 2102 字首章正文；这条 `diagnosticOnly` 记录自身不算两书六章验收。

随后使用同一原包和用户保留的会话，对两部不同作品各请求前三个可读章节，再以 `simctl terminate` 真正终止应用并重新启动，从持久检查点重新搜索、定位同一作品与章节并逐章联网。验收格式为 2，执行器为 `zhuying-source-acceptance-3.2`。

首次与重启两轮各有 11 个步骤、19 次成功原生请求、0 次失败请求。两部作品身份不同，六章身份、版本及规范化正文哈希分别唯一；重启复核的六章证据与首次逐项一致。原始两轮耗时约 35 秒、29 秒。后续应用更新复核及最新原生计数见[脱敏实测记录](artifacts/2026-11-07-legado-stage-three-live.json)。这份记录只包含固定状态、哈希、计数、进程标识和时间，不包含账号、关键词、书名、URL、正文或私有脚本。

会话状态保持 `unverified`。上述阅读结果证明已检查路径可读，没有据此宣称账号付费权限或全部线路已验证。自动化 UI 中的原创夹具有明确标记，未混入这份真实网络证据。

## 本阶段修复

- 详情初始化保留真实值类型，并按参考 `getElement(init)` 取首项。原来的 `elements(...).joined()` 将对象变为字符串，原介绍规则对 `result` 解构后访问字段失败。同一合成数据在真实 QuickJS 中作字符串／对象对照，已复现并消除该错误。普通 HTTP 响应和 JavaScript 返回的字符串仍保持字符串；不会根据文本看似 JSON 就猜成对象。
- 单次操作脚本求值额度由 128 调整到 2048，允许数百条搜索结果逐条执行 URL 规则；每次脚本的 128 次宿主调用、500 条搜索结果、元数据、请求及操作总超时继续独立限制。新增 240 条搜索结果回归。
- 受控原生 HTTP 等待从 5 秒解释器执行预算中排除；请求、总操作、桥调用和数据大小限制继续生效。普通宿主计算仍计时，没有把所有宿主等待都无限延长。
- 脚本会话纳入进程级 96 MiB 配置堆上限预留预算，默认每 VM 16 MiB。空闲 LRU 回收、操作租约、取消、重置、内存压力及后台释放有回归覆盖。该数字不是进程 RSS 上限，也不包括 WebKit 或 Swift 全部内存。16 个真实适配器并发回归使用 32 MiB 预算验证预留额度和规则间全局变量租约。
- `book.setUseReplaceRule` 真正控制书籍用户净化规则，同时刷新脚本可见 `book.readConfig`，并随书籍与加密会话持久化；书源自己的解析和替换规则继续执行。
- 资料库使用持久 UUID，避免安装更新导致容器目录变化后无法关联登录会话。已实际更新安装并比对稳定标识及保留会话。旧会话仅支持已知完整旧作用域且来源、账号匹配的精确迁移；不按文件时间、单文件或猜测账号接管未知加密记录。初次旧路径会话无法安全关联时保留原文件，用户已重新登录。
- 排队操作在入队前固定账号代际，退出或切换账号后旧登录不能重新写回；显式同账号重试启动新的 `unverified` 代际。登录完成后恢复相应阅读来源，其他来源的认证失败不会误清独立服务账号。
- 原生宿主异常只在最终未捕获 JS Error 与该次原生调用所抛对象身份一致时还原。脚本捕获宿主错误后再抛新的 TypeError，会正确报告新脚本错误；不会误报之前已处理的登录或主机错误。C 引用和 Swift 原因映射均在本次执行后释放。
- 调试结果只导出固定错误分类、规则字段及安全类型摘要；原异常、堆栈和私有值不进入报告。普通脚本失败与确实缺失的宿主能力分别分类。现有调试、登录、网络和重试入口继续复用。
- 完整验收拒绝重复正文、伪造不同版本、相同版本对应不同正文、仅空白／Unicode 格式差异和跨书复用。重启必须保存并比较第二组六章证据。旧格式、不同规则、不同账号代际以及验收期间改变上下文的记录不能沿用为当前通过结果。

详情初始化的参考位置为固定版本 [BookInfo.kt](https://github.com/gedoor/legado/blob/fd026e0/app/src/main/java/io/legado/app/model/webBook/BookInfo.kt#L53-L58)。Java／加密接口仍是独立实现的样本所需子集，参考版本、许可和范围见[兼容说明](../LEGADO-COMPATIBILITY.md)。

## 明确边界

没有可用 Android 设备／模拟器，本轮未运行参考 APK 差分；离线审计与比较工具不能冒充 APK 执行结果。其他线路、付费权限、音频、探索缓存刷新、同步 Android 网页桥和其他 Java 扩展仍按真实样本逐项适配。

还有一项非当前样本的初始化组合边界：`$.data<js>result.abstract</js>` 的 JSON 阶段向后续 JS 传入单元素数组，而参考单元素读取应传对象。本轮样本采用先脚本再 `$.data` 的顺序，已验证路径不受影响。该组合需后续独立补齐，不能由本轮成功推导任意阅读 3.0 书源均兼容。

未重新设计正式版页面、导航或阅读交互；未将验证工具或实现参数加入普通读者的操作流程。所有本轮代码与证据均以独立提交保存，便于追踪和回滚。
