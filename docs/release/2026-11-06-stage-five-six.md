# 阅山 0.6.0 开发候选

版本 0.6.0，构建 6。步骤五、六客户端功能已实现，正式模式继续复用冻结 Demo 的页面、导航、视觉组件与交互。在线／AI 按用户选择支持自定义兼容服务，密钥只在 App 内配置。本版本仍是开发候选，G3／G4 尚未通过。

## 已实现

- 多源检索独立分页与限并发、同名作品候选、明确来源和局部错误；换源按章节／上下文建议，低置信需手动确认，正文成功后事务提交新位置并保留旧版本历史。
- 主动离线队列支持章节范围、Wi-Fi、两章并发、暂停／重试／重启续传／删除，256 MiB 实际文件配额；进入后台暂停，坏队列隔离，清近期缓存不删主动下载。
- 未加密可重排 EPUB 的实际文字与本地插图导入，按 spine 排序，安全处理资源路径；长章、CDATA、Unicode 和重启续读。复用阅山排版，不复刻出版物 CSS；加密／固定版式明确拒绝。
- 中文全文搜索覆盖本地和已缓存／下载正文，列出未缓存范围，按版本校验命中并跳转；正式足迹使用真实阅读及独立朗读时长，空闲／后台／时钟变动不虚增，不重复计时。
- JSON 书源文件／HTTPS 链接导入、预览确认、导出／重导入、支持规则编辑、四步实际调试和批量检测；公开接口使用访问说明，已有书山仍使用原生登录。订阅更新由用户在前台显式检查，读过不重复提醒。
- 系统原生声音／语速、暂停继续、跨章、正文跟随和实际迷你播放器；后台会话、系统播放信息／远程命令、中断／路由状态保护，重启不自动播放。
- 自定义 HTTPS TTS／角色分析模型、WSS 地址、实际连接测试和设备 Keychain；分段 WAV 缓冲、同请求一次续接、64 MiB 音频缓存、失败和取消保留位置。
- 角色分析按章／模型／版本缓存，旁白回退、改名／声音映射／重算；分批和请求预算先检查，默认不自动跨章分析，保存失败可先重试内存结果。

操作与支持范围见 [书源约定](../COMPATIBLE-SOURCES.md) 和 [音频约定](../COMPATIBLE-AUDIO.md)。主动下载和派生音频不进入原生备份；服务配置及密钥不进入备份。备份仍以本地导入作品、个人记录、偏好、字体与主题为主。
