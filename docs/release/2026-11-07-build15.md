# 竹影 0.8.0（build 15）：不随包提供书源

build 15 保留 build 14 已整合的阅读、导入、主题与朗读功能，并移除发行包中的具体书源预置。

- 新安装、没有旧配置时，书源列表为空；不再自动加入默认原生书源，也不会在迁移或重启时补回。
- Release 不含默认站点地址、演示书源名称／地址／JSON、具名模拟检测结果。Debug Demo 的三个演示书源继续用于开发验证，不进入发行包。
- 保留导入、解析、编辑、搜索与阅读能力，地址和规则由用户提供。已有用户配置、书籍、账号数据及备份照常保留，不清空存量书库。
- 手动新建先打开空 JSON 草稿，不生成预制规则、不写入空记录；取消不落库，合法保存后才加入书源列表。
- 账号地址没有保存值时为空，不读取未知主机的钥匙串；未登录或地址为空时，不会覆盖用户已导入来源的地址。
- Release 忽略 Demo／UI 测试启动参数。应用包带有 `ZhuyingBundledSources=false`，并对实际资源和可执行文件进行独立检查，不只依赖该声明。

本地原创阅读样章、主题与通用解析协议属于软件资源和能力，未将其作为可运行书源分发。用户导入数据是设备本地数据，不随 IPA 打包。

## 验证

630 项原生单元测试、11 条相关 Debug 界面回归、1 条真实 Release 界面验收、106 项 Web 测试和 5 项语法检查通过。相关界面测试验证旧导入数据迁移／编辑、空源新建取消保存、文件及粘贴导入、主题与脚本阅读重启；两个旧测试输入／入口假设已修正并重跑通过。

真实 Release 验收使用全新隔离模拟器、空启动参数、应用包外提供的合成 JSON，依次验证：首次 0 源 → 重启 0 源 → Files 导入 1 源 → 重启保留 1 源 → 删除 → 重启仍为 0。过程没有启用 Debug 夹具，没有把外部测试 JSON 写入 App 或 IPA，验收完成后删除专用测试模拟器。

Release 模拟器 App 的 4 个 JSON 资源中具体书源定义为 0；可执行文件的 UTF-8／UTF-16 检查未发现已知默认站点和演示源标记。最终 iPhoneOS IPA 再执行同一检查，旁置 `-source-free.json` 记录结果，另有独立结构和 SHA-256 校验清单。
