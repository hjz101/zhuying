# 竹影：导入、阅读和朗读问题修复

## 行为

| 反馈 | 本轮处理 |
| --- | --- |
| 大灰狼 JSON 链接导入显示无效 | 兼容旧阅读器以名称作为 `bookSourceUrl` 的标识，允许预览、保存、去重、导出及重新导入；保留规则兼容性说明。 |
| 搜索作品打开章节失败 | 开始阅读和前后章切换跳过“第一卷”等分卷标题；受限章与不存在的章显示不同原因。 |
| JSON 文件入口缺粘贴导入 | 文件和源码页均增加“粘贴 JSON 导入”，读取后进入相同预览和确认流程。 |
| 本地文件选择无反应 | 所有入口统一使用原生 Files 复制导入；原生协调器处理系统关闭与选择回调的两种顺序，读取权限、文件提供商协调和大小限制统一处理。 |
| 应用整套主题无效 | 修复规范化设置跳过保存、无初始主题快照时未绑定持久化的漏洞；应用后预览真实阅读设置，按钮旁显示结果。 |
| 朗读中翻页立刻回跳 | 翻页、滚动、目录、滑杆、书签和全文搜索主动跳转暂时脱离朗读跟随；取消未完成的自动跨章加载，朗读继续。 |
| 阅读两分钟提示加入书架 | 未入架作品的正文在前台可见累计两分钟后询问；后台、弹层、加载和失败不计时，每本书只询问一次，拒绝记录重启后保留。 |
| 返回正文缺朗读小窗 | 正文底部沿用悬浮样式，支持暂停/继续、打开当前播放作品、关闭、返回朗读位置；收起工具栏后仍可操作。 |

## 书源边界

用户给定的真实 JSON 返回 157,920 字节，包含一个以“大灰狼融合VIP5.0”为标识的书源。使用生产解析代码验证可保存一个书源、无无效项，去重和导出后重导入通过。

该规则依赖 Android 阅读的同步 `java.ajax`、变量、Cookie 登录和跨站浏览器验证等宿主接口。竹影当前原生脚本宿主无法直接运行这些接口。本次修复导入拒绝，**不代表该大灰狼书源已能搜索或阅读**；导入预览和书源状态会明确提示。有效原生适配器和现有书源入口保留。
