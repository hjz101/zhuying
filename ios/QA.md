# iOS 原生 Demo v0.2 验收记录

日期：2026-11-04。SwiftUI 原生 iPhone App，使用内置模拟书库，无真实后端和网络调用。

## 构建与验证环境

- Xcode 26.6、iOS 26.5 Simulator；使用 iPhone 17 Pro 和 iPhone 17e 验证。
- 工程最低支持 iOS 17；其他系统版本和真实设备尚未逐一验证。
- 模拟器构建关闭代码签名。测试使用独立 UserDefaults 域，不覆盖正常运行的个人演示记录。

## 自动化测试范围

本轮最终结果：`xcodebuild test` 通过，17 项单元测试、6 条界面流程，0 失败。最终界面流程在 iPhone 17e 上运行，正常演示版本同步安装到 iPhone 17 Pro。

`YueshanTests` 共 17 项，覆盖：

- 原有书库完整性、搜索、收藏、阅读进度、数据校正、空书架和损坏存储。
- 旧 v1 快照兼容迁移，新增偏好和排序的持久化。
- 未收藏书籍的阅读历史、历史与书架排序相互独立。
- 多选批量移除、撤销恢复原顺序、重复撤销不产生重复收藏，移除不删除进度。
- 模拟更新数量随已读章节减少，回读旧章不重复增加，可手动重置演示。
- 多个屏幕尺寸、字号和横竖屏下，分页范围连续覆盖全部文字、每页实际排版不截断分配的文字。
- 段落与文字偏移在重新分页后仍落在目标页面内。
- 两侧前进区域、中间菜单与关闭轻触翻页时的规则。

`YueshanUITests` 共 6 条端到端流程：

1. 继续阅读 → 目录跳章 → 关闭目录 → 主题／字号 → 返回书架 → 继续阅读。
2. 搜索 → 详情 → 收藏 → 阅读 → 书架。
3. 左右分页 → 左右两侧均前进 → 右滑返回／左滑前进 → 关闭并恢复菜单 → 章节滑杆 → 切回滚动阅读。
4. 书架多选 → 批量移除 → 撤销 → 排序 → 检查恢复的收藏。
5. 未收藏就阅读 → 我的 → 阅读历史 → 加入书架 → 继续阅读。
6. 追更小报 → 读取更新首章 → 更新计数减少 → 手动模拟重置。

## 体验约定

- 横向模式按实际屏幕内容区分页，左滑前进、右滑返回，或轻触任一侧前进，底部箭头也可操作。
- 滚动模式默认上下滑动；启用轻触翻页后，两侧轻触移动约一屏，在章尾可进入下一章。
- 轻触正文中间可隐藏／显示工具栏；隐藏时保留“显示工具栏”入口。隐藏菜单不改变正文区域高度，避免分页突然变化。
- 进度滑杆拖动期间预览目标章，松手才提交跳转。
- 两侧轻触均前进，返回上一页使用右滑或底部箭头；不再区分左右手。
- 收藏移除保留历史与阅读进度，单本和批量移除均可撤销。
- 已安装 v0.1 的用户直接更新即可保留书架与进度，无需卸载重装。

## 演示边界

- 更新角标和追更列表明确标为模拟状态；仅为现有连载作品的末尾样章设置标记，不新增真实章节，不申请或发送系统通知。
- 触觉反馈提供可关闭的系统反馈调用，实际手感需在真实 iPhone 验证，模拟器无法表现震动。
- 数据仅保存在当前设备。正文是短篇样章，多个章节复用段落；没有云同步、真实书源、付费、离线下载或完整小说。
- 仍需在发布前完善全部机型、动态字体、VoiceOver 与真机兼容性验收。
