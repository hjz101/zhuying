# 偏好总览 · 第二版设计评审

2026-11-05。本稿仅用于设计评审，不修改 App，也不表示所述能力已经实现。交互原型源文件为同目录 `reading-preferences-overview-v2.html`。

保留“偏好总览”的简洁首页，将当前样式摘要、正文效果与四个明确分类放在一起：**主题与字体／排版与页面／翻页与手势／正文与段评**。不再设置一个囊括所有功能的“更多阅读设置”清单。

## 主题与字体

### 主题库与导入主题

主题库分为“内置／我的导入／我的创建”。每张主题卡使用同一段示例内容，直接预览纸色、正文、章节标题、段尾气泡及神人评论卡片。主题名称、作者与来源作为辅助信息；自导入主题与内置主题获得相同的预览能力。

主题详情列出包内实际包含的组件，如配色、字体引用、章节样式、段尾气泡皮肤和神评卡片主题，避免将完整主题误解为单一纸色。未包含的组件继续沿用现有设置。导入先预览，再应用。

### 字体管理

字体列表中的试字直接使用对应字体，不能仅显示字体名称或字体截图。选择后，上方正文预览同步切换；可输入自定义试字，并提供中文、标点、数字和字母混排示例。导入、收藏与查找集中在字体管理页，缺字使用回退字体时明确提示。

## 排版与页面

“排版与页面”只保留三个关联入口：**正文排版／章节标题／页眉与页脚**。正文排版与页面边距合并，不再分别跳转两页。

### 正文排版与边距合并

字号、字重、行距、段距、缩进、对齐和上／下／左／右四边留白在同一个页面调整，并共用上方正文预览。布局从文字参数到页面留白排列，调字号或间距时可以直接观察正文宽度和每页容纳量，不必反复退出页面。

左右边距提供联动开关；解除联动后分别设置左边距和右边距，允许左边较大、右边较小。上、下留白独立设置。预览同步反映正文实际位置，并限制边距总量，保留可读空间。

### 章节标题的唯一入口

章节标题仅在“排版与页面 → 章节标题”中管理。页面先明确选择“跟随主题／自定义”，不能只有一个含糊的“新建”按钮。跟随主题时显示当前主题提供的标题效果与来源；切换自定义时，以当前有效标题样式作为起点，允许修改而不改写主题包本身。

自定义页同时提供视觉控件与 CSS 编辑：视觉控件调整标题字号、字重、颜色、对齐、字间距、边框和留白，CSS 区支持新建、导入、编辑和即时预览。视觉控件与 CSS 共用一份标题样式结果，修改任一侧都会更新同一预览，避免出现两套独立样式。提供“恢复跟随主题”操作。

主题页只展示“主题包包含章节样式”“当前跟随主题”或“当前已自定义”等状态；若需要查看或编辑，跳到同一个章节标题页，不维护第二套设置。

章节 CSS 只作用于章节标题区域，可调整字体、字号、颜色、对齐、间距、背景和装饰。导入或编辑后，示例章节标题实时变化，并反馈不兼容或无效规则。原生 SwiftUI 阅读器不能直接运行任意网页 CSS；实际实施需要限定支持范围并建立 CSS 到原生样式的兼容层。该兼容层目前尚未实现，原型中的浏览器预览不代表 App 已支持完整 CSS。

### 页眉与页脚

页眉、页脚分别启停，各自拥有可自由布局的独立区域，不限制为左／中／右三个固定槽位。每个区域可以添加多个元素，内容可选书名、章节、时间、进度、页码或自定义文字；分页模式可展示页码，滚动模式使用章节进度。

选择元素后，既能在区域预览内拖动，也能用 X／Y 坐标精调位置；另提供元素宽度、字号与颜色调整。位置坐标相对所属页眉或页脚区域，支持重新选择和删除元素。拖动受区域边界约束，调整宽度或文字大小后也能直观看到是否越界；细调不依赖手指拖拽的精度。

页眉和页脚的区域高度分别设置，并在页面排版时预留，再叠加它们与正文的间隙。增加区域高度会减少正文可用高度，正文不会被元素覆盖。正文四边留白、页眉区域、页脚区域在同一个页面效果中呈现，使用户能区分“页边留白”与“页眉页脚自身占用的空间”。

## 翻页与手势

滚动／分页是阅读模式；覆盖、平移、无动画、仿真是分页效果，只在选择分页时展开。轻触翻页、触觉反馈及手势说明放在同一分类。两个模式继续共享阅读位置。

## 正文与段评

### 从关键词高亮升级为正文样式规则

规则库支持新建、导入、排序、启停及样式预览。每条规则由“匹配对象或条件 → 呈现样式 → 作用范围”组成，关键词高亮只是一种匹配与呈现组合。

对话、系统消息、诗词和章节首段首字下沉作为可修改模板；可使用关键词、正则或已识别的文本结构作为条件。规则编辑页显示示例内容中的命中范围与未命中反馈，不将诗词或对话识别描述为无条件准确。首字下沉属于排版变换，不再等同于给固定字染色。重叠规则的优先级与冲突结果需要清楚可见。

### 段尾气泡与神人评论

- **段尾气泡**：紧接段落末尾，显示评论数量并打开该段评论。皮肤可调整气泡形状、计数文字、颜色与装饰，始终保留可点击区域。
- **神人评论**：作为对应段落下方的精选评论卡片呈现，可控制数量或折叠。卡片主题可采用液态玻璃、画框、纯文字等形式，独立调整背景、边框、圆角、头像与文字样式。

管理页分为“段尾气泡／神人评论”，分别设置显示行为和外观。两类组件都支持随完整阅读主题导入，也支持独立创建或导入皮肤；不得把段尾气泡与段下评论卡片混成同一种组件。

## 主题继承与个人覆盖

外观采用“应用默认 → 当前主题包 → 用户单项自定义”的优先级。字体、章节标题、正文样式规则、段尾气泡和神评卡片等组件显示“跟随主题／自定义”状态；允许一键恢复跟随。

应用新主题时，默认保留用户明确设置的单项覆盖，并在主题详情中列出这些覆盖；提供主动选择使用包内样式的操作。主题包没有携带某个组件时，不清空用户当前设置。全局偏好与规则的作用范围分别表达，不将当前书独有规则误当成全局主题。

## 原型与实现边界

原型演示信息组织、主题／字体预览入口、章节标题的视觉控件与 CSS 自定义、合并后的正文排版和四边留白、页眉页脚多元素自由布局、正文样式模板及两种评论组件之间的关系。预览中的导入与创建能力以原型实际行为为准，不能据此宣称已经完成文件持久化、原生渲染、真实评论服务或跨设备同步。

目前真正作用于原生阅读器并持久化的基础设置仍以 App 现有实现为准。实施本方案时，应统一主题库、字体、排版、章节样式和评论皮肤的数据来源与继承关系，并新增相应模型、迁移、渲染与测试。本次设计评审不修改这些 App 能力。

## 翻页方式补充

翻页页按“阅读方式 → 对应效果 → 触发手势”排列，默认直接打开此页以便评审。

| 阅读方式 | 效果选择 | 滑动动作 |
| --- | --- | --- |
| 上下滚动 | 连续跟手，不显示逐页动画选项 | 上滑继续、下滑回看 |
| 左右翻页 | 平移、覆盖、仿真、无动画 | 左滑下一页、右滑上一页 |
| 上下翻页 | 平移、覆盖、无动画 | 上滑下一页、下滑上一页 |

左右与上下逐页动画分别记忆；切换方向不会覆盖另一方向的选择。轻触翻页是独立触发方式，开启后可轻点左右两侧前进，中间显示菜单；滚动模式轻触前进约一屏。

原型支持“试翻下一页／试向上滚动”按钮，以及在示例区域滑动；仿真用纸页旋转表达卷页含义，仅为交互示意，不代表原生 App 已实现仿真、上下分页或完整手指跟随物理效果。原型遵循系统减少动态效果偏好。

本轮验证：34 项 Node 测试通过（新增 4 项），浏览器验证左右仿真、上下覆盖试翻及切换方向保留动画。原生 App 未改动。
