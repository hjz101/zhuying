# 竹影网页草稿验收记录（历史参考）

首发平台现已明确为 iOS，原生版本及最新验收记录见 `ios/`。本文仅记录之前网页草稿的验证结果。

日期：2026-11-04。验证对象：本地静态网页 Demo；数据、封面和正文均为原创模拟内容。

## 自动化验证

- `npm run check`：检查应用、数据、状态模块与静态服务的 JavaScript 语法。
- `npm test`：12 项 Node.js 自动化测试，覆盖首次初始化、书名与作者搜索、题材交集、收藏与去重、移除后保留进度、未收藏阅读、最近阅读排序、非法章节边界、数据往返保存、空书架保存、损坏或不可用存储、保存数据规范化、路由及全部示例正文完整性。

## 浏览器验收

在 Codex 内置浏览器实际操作以下流程，结果通过：

| 场景 | 验证结果 |
| --- | --- |
| 书架 → 发现 → 作者搜索 | 搜索“林间渡”只返回《长风渡山海》 |
| 搜索 → 详情 → 继续阅读 | 正确进入已有记录的第三章，详情展示相应进度 |
| 阅读偏好 | 切换夜读、24 px 字号、宽松行距，正文对应变为 24 px / 48 px |
| 目录与切章 | 目录跳到第五章，下一章进入第六章，章名和地址一致 |
| 刷新恢复 | 第六章滚动后刷新，仍在同一段落；同一视口下滚动位置一致，主题与字号保留 |
| 书架筛选与布局 | “尚未开始”初始返回 3 本，网格与列表正常切换 |
| 题材筛选 | “仙侠”只展示《云海问道》 |
| 新增收藏 | 《云海问道》由未收藏变为已在书架，刷新后仍保留 |
| 移除与撤销 | 移出收藏后可点击撤销重新加入 |
| 第一章与最后一章 | 第一章的上一章禁用；末章的下一章禁用并显示已是最后一章 |
| 空搜索结果 | 输入不存在的故事显示空状态与浏览全部入口 |
| 手机排版 | 在 360、390、430 CSS px 宽度下检查书架和发现页，无横向溢出；390 宽度检查详情和阅读器，无横向溢出 |
| 桌面排版 | 1440 CSS px 宽度下显示侧栏、继续阅读卡片、阅读随记与四列书架 |

## 范围与限制

- 本轮浏览器测试使用模拟视口，不等同于全部浏览器或真实手机兼容性测试。
- 无真实后端；没有测试、连接或执行用户提供的书源配置。
- 收藏、进度、偏好仅在当前浏览器保存；不支持跨设备同步。
- 全部正文为短篇样章，多个章节复用各作品的示例段落，重点验证交互而非提供完整小说。
- 模拟书库一次返回全部匹配结果，没有服务端分页、请求超时和真实网络错误状态。
- 没有实现离线缓存、付费或受限章节、账号与统计服务。
