# 竹影：统一主题管理入口

按用户要求，不再把「主题」与「全局主题」展示为两套管理入口。保留「我的 → 主题管理」原入口，进入后直接显示主题选择、制作、导入、打包分享和恢复。

同页使用四个分类：

- **主题**：应用界面、完整阅读外观及其制作、导入、导出。
- **阅读搭配**：既有阅读配色及标题／气泡组合，可独立调整，保留筛选、收藏、管理与混搭。
- **章节标题**：既有章节 CSS 资源及其预览、应用。
- **段评气泡**：既有气泡 SVG 资源及其预览、应用。

不增加第二级「全局主题」页面。四个分类只切换当前内容，返回一次即可回到上级页面；现有工具箱、阅读偏好和个人页面入口都进入同一个管理页面。除该主题入口合并外，不更改书架、底部导航或阅读页面结构。

「导入主题包」同时接受 `.zhuyingtheme`、ZIP 和阅读 JSON。JSON 沿用现有原生解析、大小限制、资源验证和去重逻辑；导入后切到「阅读搭配」并显示结果。完整主题包仍先预览，由用户选择仅保存、完整应用或混搭。旧阅读搭配不会被冒充为包含全部界面资源的完整主题。

新增界面回归检查：从个人页直达、无嵌套入口、四类资源切换、返回层级。更新既有回归：新管理页主题切换／重启／恢复、实际文件 JSON 与完整主题包导入、AI 制作资料导出、旧标题／气泡混搭与管理、正式书库重启、工具箱入口。
