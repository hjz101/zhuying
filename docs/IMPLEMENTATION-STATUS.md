## 继续开发：原页面接入正式存储

正式模式现在由同一协调器恢复书架、正文、分组、进度与排版偏好；Demo 继续使用原存储路径和页面。导入确认等待正文和数据库提交完成，再更新书架及成功数量。启动迁移期间暂停操作，迁移失败保留旧文件与记录并提供重试；完成标记写入后，重启只读取新仓库，不再被过期的旧快照覆盖。

持续滚动时每 250 ms 合并保存，切章立即排入写入队列，退出阅读和进入后台补存，后台申请系统允许的短时保存时间。所有写入与导入串行，后续保存读取已提交导入后的完整书架，避免排版变更覆盖刚导入的作品。写入失败保持上次有效数据库、展示错误并保留待保存状态，后续补存可重试。

当前仍以完整本地作品投影复用 Demo 阅读器；尚未实现 T015 的按章懒加载，主题／字体资源独立模块与完整书签交互也未纳入本轮。G2／G3 保持未通过，真实书山在线流程仍等待应用内登录与后续接入。
